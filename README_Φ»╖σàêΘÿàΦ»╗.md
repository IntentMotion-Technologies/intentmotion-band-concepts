# IntentMotion Concept Lab v1 — 五款独立产品介绍页

这是**可离线打开的静态网页原型**，不需要下载 GitHub Skill、不需要 npm、不需要搭建数据库。共 6 个 HTML 页面：

- `index.html`：五款产品总入口
- `run.html`：跑步领地
- `play.html`：隔空游戏
- `type.html`：空中手写
- `robo.html`：机器人遥操作
- `avatar.html`：虚拟角色控制

网页的所有核心图形由 SVG 和 CSS 绘制，可离线查看。网页有动效，但**不是实机操作录像**，页内有相应说明。每页提供 15 秒实机展示视频的拍摄分镜草案。

## 1. 立即预览

解压整个 ZIP，双击 `index.html` 即可。建议使用 Edge/Chrome；如需通过本地服务器浏览，在此文件夹运行：

```powershell
py -m http.server 8000
```

浏览器打开 `http://localhost:8000/index.html`。

## 2. 关于购买意向表单，非常重要

**目前默认是演示模式，不能远程收集客户！**

不配置表单接口时，每页点击“提交购买意向”只会把数据保存到**访客自己的浏览器 localStorage**。你本人无法在另一个设备读取客户的意向；这只是让你检查交互流程是否正确。总入口的「导出本机演示反馈 CSV」只导出当前浏览器的数据。

正式推广前要接入实际的数据收集系统：

1. 选择 Formspree、金数据、腾讯问卷或自有后端；
2. 如果选择兼容 JSON POST 的表单服务，在 `assets/config.js` 中填写 `formEndpoint`；不同服务可能需要调整 `assets/app.js` 的请求方式；
3. 收集邮箱之前，必须配置公开的隐私说明 URL（`privacyUrl`），说明目的、保存期限和联系/删除方式；
4. 用两台不同设备提交测试并在管理后台确认记录确实到达，检查 CSV 导出和重复提交控制；
5. 确认移动端、隐私合规、备案（如适用）、社群推广链路后再公开发布。

**特别提醒：** 现有表单不包含支付功能，也不产生预售订单，不应在正式平台上把概念素材当成已验收的功能展示。

## 3. 定制内容

- 改五款标题、用户场景、价格测试：在各自 `.html` 找对应文案；高级批量生成时可修改上一级构建脚本的产品数据。
- 改视觉颜色：`assets/style.css` 的 `body[data-product=...]`。
- 添加真实视频：建议等各功能做出可复现原型后录制；可把“15 秒分镜”改成 `<video controls poster="...">`，务必标明概念与实测差异。
- 图片/ logo：现在的产品插画不是工业设计定稿，不代表真实量产外观。

## 4. 发布路径建议

先在线上预览站托管该项目（GitHub Pages / Cloudflare Pages / 国内静态托管均可，但应考虑中国境内访问情况和当地网站备案要求）。不要把 `assets/config.js` 放任何秘密 API token 或私钥；此处只能放可公开的表单收集地址。

市场验证时让五款产品尽量获得相近质量的用户流量。不要只比较点赞数；更值得关注：意向转化率、愿付价格、用户来源、愿意参加试用的人数及实际原型测试结果。
