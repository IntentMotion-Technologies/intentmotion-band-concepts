01 / WHY THIS PRODUCT

一个清晰场景，
而不是一百种功能。

不是替代所有键鼠手柄，而是先让几个动作好用、好玩。

USE CASE / 01

轻动作触发

研究轻捏、握拳等肌肉活动与明确的游戏操作指令之间的映射。

USE CASE / 02

专注特定场景

先为一个小游戏或少数适配场景实现准确、低负担的操作。

USE CASE / 03

个性化手势

不同人的肌电信号存在差异，因此需设计个人校准和误触控制。

THE CORE INTERACTION
PINCH → ACTION

真正的购买理由是舒服、可靠、低延迟的操作体验，不是“肌电”这个词。

02 / HOW IT WORKS

实际体验，
应该只有三步。

1

戴上腕带并校准

采集个人手势信号，确认设备状态。

2

选择游戏操作映射

例如捏合=确认、握拳=技能、腕部转动=切换。

3

进入适配的游戏

用手势触发可视化操作，并记录误触与响应表现。
