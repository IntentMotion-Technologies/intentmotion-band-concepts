01 / WHY THIS PRODUCT

一个清晰场景，
而不是一百种功能。

这条路线已有仿真联动基础，但物理机器人安全与稳定性必须独立验证。

USE CASE / 01

已具备仿真基础

现有 W2K IMU → RoboDK 机械臂关节动作跟随已做过真实设备联调。

USE CASE / 02

开发者优先

先提供标准化输入、仿真适配和可检查的动作边界。

USE CASE / 03

长期扩展控制

再逐步探索抓取、末端控制与多机器人场景，保持安全门控。

02 / HOW IT WORKS

实际体验，
应该只有三步。

1

佩戴并校准

确认腕带 IMU 数据与可用动作范围。

2

进入仿真环境

将腕部运动映射到仿真控制器。

3

审核动作与安全限制

观察位置、关节限制、误触后，再研究真实机器人接入。
