01 / WHY THIS PRODUCT

一个清晰场景，
而不是一百种功能。

不先吹“替代键盘”，先从少量可重复的字符和快捷命令做起。

USE CASE / 01

从动作到文字

探索连续手指动作、腕部轨迹与文字候选之间的学习关系。

USE CASE / 02

先做有限输入

从少量字符、数字、固定短语或快捷命令开始建立准确率证据。

USE CASE / 03

适配未来设备

未来可考虑配合 AR 眼镜、智能终端和特殊工作场景。

02 / HOW IT WORKS

实际体验，
应该只有三步。

1

完成个人校准

让算法学习用户独特的肌肉和动作习惯。

2

书写有限字符

通过设计好的动作词表采集输入数据。

3

确认候选文本

系统显示候选结果，用户确认或纠错。
